# 📈 Stock Portfolio Tracker

## Description
A simple Python-based Stock Portfolio Tracker that calculates the total investment value using predefined stock prices.

## Features
- User inputs stock names and quantities
- Uses a dictionary for stock prices
- Calculates total investment
- Saves portfolio details to CSV
- Console-based application

## Technologies Used
- Python
- Dictionary
- File Handling
- CSV
- Pandas

## Project Structure

Stock-Portfolio-Tracker/
│── StockPortfolio.ipynb
│── stock_tracker.py
│── portfolio.csv

## How to Run

```bash
python stock_tracker.py
```
