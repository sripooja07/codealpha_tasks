# 🤖 Basic Chatbot

## Description
A simple rule-based chatbot developed in Python that responds to predefined user inputs.

## Features
- Responds to greetings
- Answers simple questions
- Ends conversation with "bye"
- Uses functions and loops
- Console-based chatbot

## Technologies Used
- Python

## Concepts Used
- If-Elif Statements
- Functions
- Loops
- Input/Output

## Project Structure

Basic-Chatbot/
│── BasicChatbot.ipynb
│── chatbot.py
│── README.md

## How to Run

```bash
python chatbot.py
```

## Sample Output

You: hello
Bot: Hi!

You: how are you
Bot: I'm fine, thanks!

You: bye
Bot: Goodbye!
